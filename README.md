# Student Grade Analyzer

## Overview
The Student Grade Analyzer is a Python script that analyzes student grades, providing insights such as the highest and lowest grades, students who achieved a grade of 85 or higher, and overall performance metrics.

## Features
- Find the highest and lowest grades among students.
- List students with grades of 85 or higher.
- Assign letter grades based on numeric grades.
- Calculate total and average grades.
- Assess student performance as pass or fail.

## Installation
To run the script, ensure you have Python installed on your machine. You can download it from [python.org](https://www.python.org/downloads/).

## Usage
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd student-grade-analyzer
   ```
3. Run the script:
   ```
   python grade_analyzer.py
   ```

## Output
The script will print the following information:
- The name of the student with the highest grade and their grade.
- The name of the student with the lowest grade and their grade.
- A list of students with grades of 85 or higher.
- Each student's name along with their corresponding letter grade.
- The total and average grades of all students.
- Each student's performance status (Pass/Fail).
